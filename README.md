# Rishi Raj Singh — Portfolio

Personal portfolio of **Rishi Raj Singh**, Full Stack Software Engineer in Noida, India.
Java · Spring Boot · React · Next.js · microservices · fintech & lending systems (LMS / LOS).

**Live site:** https://rishirajsingh1.github.io/Rishi-Portfolio/
**Résumé:** https://rishirajsingh1.github.io/Rishi-Portfolio/resume.html

Built with plain HTML, CSS and vanilla JavaScript. GSAP, ScrollTrigger and Lenis are pinned and served locally in `assets/vendor/`. Dark and light themes, responsive project case studies and live GitHub stats. There is no audio control or audio playback.

Content and the downloadable PDF are aligned with the October 4, 2026 resume. The experience metrics describe contributions within Lentra's 150+ service ecosystem, approximately 25% lower transaction latency, and roughly 30% less maintenance overhead at Tech Mahindra.

`github.js` loads the public profile and all public repository pages directly from GitHub's REST API on each visit. Counts are not hardcoded. The language chart groups repositories by their primary language, excluding repositories without one. API failures or rate limits show an unavailable state instead of old snapshot data. No API token is embedded in the site.

Preview locally with `python3 -m http.server 8765` and visit `http://localhost:8765`. There is no build step.

The project section features FORM ATHLETIC, FOLD & FIRE and VÉRAULT, with local screenshots of the deployed websites, links to the live demos and GitHub source, and an email invitation for custom website enquiries. SchoolM and Rishi Tracker remain under application engineering. Screenshots are stored in `assets/img/projects/` and do not require loading another website inside the portfolio.

The pages use a Content Security Policy that permits local scripts, Google Fonts and the public GitHub API, while blocking inline executable scripts, frames, plugins and form submissions. This is defense in depth; it does not remove a Google Safe Browsing listing. See [the security review notes](tools/SECURITY-REVIEW.md) for the confirmed warning and remaining owner action.
